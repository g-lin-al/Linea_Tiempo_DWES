Línea temporal - Tecnologías Web

  • 1993

    • HTML
      Lenguaje de marcas que define una estructura básica y un código para los contenidos de una página web.

      Ventajas: fácil de aprender, rápido de cargar y muy ligero, lo utilizan todos los navegadores de uso cotidiano
      Desventajas: largo de escribir, tedioso de mantener y analizar en proyectos grandes

  • 1995

    • CSS 1
      Lenguaje de hoja de estilos en cascada, para definir la presentación del documento escrito en un lenguaje de marcas.

      Ventajas: maquetación del diseño separada, permite diseño responsive, reusabilidad
      Desventajas: problemas de compatibilidad entre navegadores, extensión elevada en proyectos complejos
    • Apache 1.0
      Servidor web HTTP de código abierto para UNIX, Windows y macOS entre otros.

      Ventajas: código abierto, compatibilidad elevada, características de seguridad robustas
      Desventajas: más lento frente a otros servicios, complejidad elevada en la configuración
    • HTML 2
    • PHP 1.0
      Lenguaje de script de uso general usado especialmente en el desarrollo web para el desarrollo de aplicaciones, operando en el lado del servidor.

      Ventajas: open source, independencia de la plataforma, flexibilidad para ser usado con otros lenguajes
      Desventajas: el tipado débil puede crear problemas, algunos frameworks no funcionan igual que la versión general

  • 1997

    • HTML 3
      Eliminación de las fórmulas matemáticas.
    • HTML 4
      Tres variaciones diferentes con distintos tipos de restricciones.
    • JavaScript ECMAScript 1
      Lenguaje de programación interpretado y orientado a objetos, utilizado principalmente en el lado cliente e implementado como parte de un navegador web.

      Ventajas: gran compatibilidad con todos los navegadores, uso en frontend y backend, open source
      Desventajas: un error no gestionado puede paralizar todo el código, todo el código puede ser visto

  • 1998

    • CSS 2.1
      Funciones propias de div y de posicionamiento relativo/absoluto/fijo.
    • JavaScript ECMAScript 2
      Cambios menores en sintaxis
    • PHP 3.0
      Interfaz robusta para bases de datos, protocolos, APIs y módulos

  • 1999

    • JavaScript ECMAScript 3
      Inclusión de las expresiones regulares, control de errores, bucles do-while, y más

  • 2000

    • PHP 4.0
      Añade un sistema de parsing de dos fases (motor Zend)

  • 2002

    • Apache 2.0
      Compatibilidad mejorada con software basado en GPL, mejorando licencias
    • .NET Framework 1.0
      Framework de Microsoft que permite un rápido desarrollo de aplicaciones, con énfasis en la transparencia de redes e independencia de plataforma de hardware.

      Ventajas: seguridad, escalabilidad, provee un entorno completo en características
      Desventajas: fugas de memoria, curva de aprendizaje pronunciada

  • 2004

    • PHP 5.0
      Motor Zend II con un nuevo modelo de objetos

  • 2005

    • Django 0.90
      Framework de desarrollo web open source bajo Python que sigue el diseño MVC.

      Ventajas: escalabilidad, seguridad robusta, componentes predefinidos útiles
      Desventajas: muy monolítico, flexibilidad limitada, curva de aprendizaje pronunciada
    • .NET Framework 2.0
      Cese del soporte a varias versiones de Windows antiguas, clases parciales, tipos nulleables

  • 2006

    • .NET Framework 3.0
      Windows Server 2008 como componente opcional, sin cambios mayores en la arquitectura interna

  • 2007

    • Zend Server 1.0
      Servidor de aplicaciones web para ejecutar y administrar aplicaciones PHP.

      Ventajas: útil para tener un entorno full stack centralizado, posee interfaz gráfica
      Desventajas: precio elevado, puede replicarse su funcionalidad

  • 2008

    • Django 1.0
      Unicode, admin. desacoplado
    • MySQL 5.1
      Sistema de gestión de bases de datos relacional de Oracle Corporation, considerada la base de datos open source más popular para desarrollo web

      Ventajas: flexible, estable, open source
      Desventajas: curva de aprendizaje algo más pronunciada que otros servicios, falta de algunas features todavía en desarrollo

  • 2009

    • JavaScript ECMAScript 5
      Soporte para JSON, nuevos métodos de array y de objetos, entre otros cambios
    • MariaDB 5.1.38
      Sistema de gestión de base de datos relacionales de código abierto, que se bifurcó de MySQL para poder escapar de las restricciones de Oracle

      Ventajas: mejor rendimiento que MySQL de forma general, open source, compatibilidad con MySQL
      Desventajas: sin soporte empresarial de cara a proyectos grandes, no es ideal para todo tipo de aplicaciones

  • 2010

    • .NET Framework 4.0
      Nuevas características de Visual Basic .NET y C#, se incluye el CLR 4.0

  • 2011

    • CSS 2.1
      Eliminación de funcionalidades poco soportadas
    • CSS 3
      Modularización
    • Laravel 1.0
      Framework open source para desarrollar aplicaciones y servicios web con PHP, que intenta evitar el código “espagueti” con su simplicidad

      Ventajas: migración de datos fácil, curva de aprendizaje suave, escalabilidad
      Desventajas: soporte limitado, más lento que otras alternativas, coste de mantenimiento elevado
    • Laravel 2.0

  • 2012

    • Apache 2.4
      Soporte para diversas plataformas
    • Zend Server 2.0
    • Laravel 3.0

  • 2013

    • Node.js 0.10.x
      Entorno en tiempo de ejecución multiplataforma, de código abierto, para la capa del servidor y basado en JavaScript

      Ventajas: rápido, muy escalable, tiene un mecanismo para tratar errores integrado incluso en tiempo de ejecución
      Desventajas: API inestable, modelo de programación asíncrono, no está hecho para tareas que requieran mucha CPU
    • Laravel 4.0
      Prioridad de queues

  • 2014

    • HTML 5
      Versión “final” de HTML en desarrollo perpetuo, añade al lenguaje soporte para multimedia, simplifica el lenguaje para ser más legible, entre otras cosas
    • MariaDB 10.0.10
      Se prepara el proyecto de las versiones de MySQL, se permite el uso de PL/SQL

  • 2015

    • JavaScript ECMAScript 6
      Palabras clave “let” y “const” para variables y constantes. Definición de parámetros por defecto. Adición de clases. Bucles for-in. Otros cambios
    • Node.js 4.x
    • PHP 7.0
      Declaración de tipos de retorno en funciones
    • Laravel 5.0
      Estructura interna nueva, form requests

  • 2016

    • Node.js 6.x
    • Svelte 1
      Compilador para front end, open source y gratuito. La compilación de una aplicación bajo Svelte genera código para manipular el DOM, reduciendo así el tamaño de los archivos proporcionando un rendimiento mayor. Convierte el código a Javascript en el proceso de compilado

      Ventajas: no es necesario el uso de DOM de manera virtual, mejora la lectura del Javascript al que se compila
      Desventajas: las herramientas de desarrollo no están muy extendidas todavía, comunidad pequeña

  • 2017

    • Node.js 8.x
    • Django 2.0
      Soporte para Python 3

  • 2018

    • Node.js 10.x
    • MySQL 8.0
      Diccionario de datos integrado, administración de recursos y seguridad mejoradas, mejoras en InnoDB
    • Svelte 2
      Correción de errores en sintaxis

  • 2019

    • Node.js 12.x
    • Django 3.0
      Soporte ASGI
    • Jakarta EE 8
      Plataforma de programación, parte de la Plataforma Java, para desarrollar y ejecutar software en dicho lenguaje

      Ventajas: amplia comunidad, mantenible y escalable fácilmente por su filosofía estandarizada
      Desventajas: curva de aprendizaje pronunciada, costoso en recursos
    • Laravel 6 LTS
      Excepciones más detalladas
    • Svelte 3
      Realizada en Typescript. Se repensó la reactividad usando el compilador para mandar instrucciones en segundo plano

  • 2020

    • Node.js 14.x
    • Jakarta EE 9
      Espacio de nombre del a API cambiado de Javax a Jakarta
    • PHP 8
      Rendimiento mejorado, expresiones match, operador nullsafe (?->)
    • Laravel 7
      Cliente HTTP, soporte para CORS
    • Laravel 8
      Modo Mantenimiento mejorado, el paginator usa el framework Tailwind por defecto

  • 2021

    • Node.js 16.x
    • Django 4.0
      Implementación de zonas horarias por defecto, hashing de contraseñas scripteado

  • 2022

    • Node.js 18.x
    • Jakarta EE 10
      Eliminación de objetos obsoletos en varios servicios
    • Laravel 9
      Framework mejorado para el uso de PHP 8
    • Astro 1.0
      Framework de aplicaciones web basado en JavaScript open source orientado a contenido, como foros o blogs

      Ventajas: ligereza y velocidad
      Desventajas: compatibilidad limitada con otros frameworks Framework de aplicaciones web open source y basado en Javascript, orientado al contenido similar a blogs o foros. Es ligero y eficiente en proyectos de pequeño o mediano tamaño

  • 2023

    • MariaDB 11.0.2
      Búsqueda de vectores
    • Node.js 20.x
    • Django 5.0
      Valores por defecto computados por la base de datos, más opciones para declarar opciones de campos
    • Laravel 10
      Perfiles de testeo, capa de abstracción para interactuar con procesos
    • Svelte 4
      Vuelta a Javascript. Versión de mantenimiento que aumentó el rendimiento
    • Astro 2.0
      Renderizado híbrido, colecciones de contenido
    • Astro 3.0
      Rendimiento del renderizado acelerado, optimización de imágenes
    • Astro 4.0
      Documentación rediseñada, nueva API de transiciones para vistas de páginas

  • 2024

    • Node.js 22.x
    • MySQL 9.0
      Nuevo tipo VECTOR, mejoras en optimizadores
    • Laravel 11
      Nueva estructura para centralizar las diversas aplicaciones del framework, limitador de rate por segundo
    • Svelte 5
      Reescritura del framework desde los cimientos, cambiando conceptos como la reactividad y la reusabilidad. Inclusión de las runas (macros parecidas a funciones, usadas para declarar el estado reactivo de partes del código), y de snippets de código reutilizable en cualquier lugar del proyecto
    • Astro 5.0
      Server islands (llevando el concepto de la arquitectura en islas a los servidores)

  • 2025

    • MariaDB 12.0.2
      Extensión en la compatibilidad con Oracle, seguridad avanzada, mejoras en la optimización de querys
    • Node.js 24.x
    • Django 6.0
      Tareas en segundo plano, API actualizada de correo bajo Python
    • Jakarta EE 11
      Soporte para Java Records, soporte para Virtual Threads
    • Laravel 12
      Sigue la línea de mejoras de la versión 11, starter kits para las aplicaciones

  • 2026

    • MariaDB 13.0.2
      SQL procedural expandido, mejoras en la observación de datos
    • Node.js 26.x
    • Laravel 13
      Versión centrada en integrar IA
    • Astro 6.0
      Soporte para Cloudflare mejorado, colecciones de contenido en vivo, varias mejoras experimentales
    • Astro 7.0
      Routing avanzado, mejoras para IA
